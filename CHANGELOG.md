# Changelog

## 0.4.2-ru-USA6-Beach

- Add the DOA3 outlined multitouch overlay with two sticks and an eight-way D-pad.
- Add independent persistent button assignments for touch and gamepad.
- Mirror left-stick directions to the D-pad while retaining analog axes.
- Add in-game dragging of controls, with save, reset, cancel, and persistent positions.
- Add in-game settings through the gear and Select menu.
- Add 3× rendering and live 1×/2×/3× and aspect changes without restarting gameplay.
- Preserve color targets during resolution changes and retain the previous resolution on allocation failure.
- Rebuild the native core and both Java layers; retain USA6 importer and Beach artwork.

## 0.4.1-ru-USA6-Beach

- Published the Beach launcher, USA6 ISO importer, and unchanged USA5 native core.
