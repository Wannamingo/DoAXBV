# Contributing

Bug reports and focused pull requests are welcome. The APK combines the Beach 0.4.1 launcher, USA6 Java ISO importer, and unchanged USA5 native core. State which layer you changed and what you actually tested.

Preserve author notices and licenses. Keep game files, generated original-game code, private keys, local receipts, and personal paths out of the public tree. Fix the generator and regenerate locally rather than hand-editing generated C. The public export omits private build inputs; see [build notes](docs/building.md).

Сообщения об ошибках и небольшие pull request приветствуются. Указывайте часть проекта, проверенное поведение и шаги воспроизведения. Сохраняйте авторство и лицензии; не добавляйте игровые файлы, сгенерированный код игры, приватные ключи, локальные отчёты или личные пути.
